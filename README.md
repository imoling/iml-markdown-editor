本地 Markdown 编辑器，为长期写作和记笔记设计。界面只保留必要的东西：左边一棵笔记库树，中间一页纸，其余交给快捷键、斜杠菜单和侧边栏。笔记就是普通的 `.md` 文件，放在你自己的文件夹里，随时可以用别的工具打开。

**写作助手、问你的笔记、实时转写、本机生图 —— 四件事全在这台电脑上完成**，模型用到才下载，笔记和声音都不出门。

## 特性

### 🖼 想要的图，这台电脑自己画（26.5）

- **本机生图**：空行按空格 → 「AI 配图」，说一句想要什么，这台电脑自己画（stable-diffusion.cpp + GGUF 权重，全程离线）。两个模型可选：**Z-Image Turbo**（6.7 GB，八步出图，M 系列上 768×768 约三分钟）或 **Qwen-Image 2.1**（10.3 GB，更细但慢七倍）；尺寸、步数、模型都在「智能 → AI 配图」里选，也能继续用网络服务
- **等的这几分钟看得见**：正文里先占一块位，写着提示词和进度——腾内存 → 读模型 N% → 出图 N/M 步（按每步秒数算还剩多久）→ 最后一步，画完原地换成真图。占位块只是显示层，画到一半保存文件、落盘的还是原文；点它就能不要了
- **几个模型按内存自己排队**：对话与嵌入合成一组一起启停，转写用时自动起、用完自己退，生图出图时才起；占多少按实测算（不靠文件大小猜），不够时才请人让位、让完自己回来，对方正在干活就等它干完。「智能 → 本机资源」一眼看清谁在跑、各占多少、空闲多久自动停
- **标题与列表折叠**：标题左边的箭头收起整节，列表项有子项时也能收；`⌥⌘[` 折叠、`⌥⌘]` 展开。收起来的只是不显示，文件一个字都没动
- **转写收电脑放出来的声音**（macOS）：网课、戴耳机开线上会议时对方说的话也能转；识别照样在本机完成，声音不上传
- **复制为公众号格式**：选个主题、看着手机预览调，一键复制，粘到公众号编辑器就是排好的版
- **日记**：月历按这一天写了多少字填深浅（像 GitHub 的格子）；新建日记跟着你已有的目录习惯走——`日记/2026/09/2026-09-23.md` 这种分法也认
- 修复：导出 PDF 的代码块与表格（#2）、可用内存算少一半导致「内存不够」、腾内存失败后模型一直停着没人管

### 🧠 本机智能，笔记不出门（26.4）

- **区分说话人**：每句话定稿时在本机算一个声纹（3D-Speaker CAM++，27 MB，可选下载），够像就归给已有的人，不像就是新来的「说话人 N」；面板上一人一个颜色，点名字改名，改成已有的名字就是合并；「这是我」记住你的声纹，以后每场自动标成「我」。声纹只在这台电脑上算、只存在这台电脑上
- **转写一段录音**：手机录的会议、课程音频（m4a / mp3 / wav / flac / ogg / webm）选一个文件就转，约 40 倍速、全程离线；和现场转写一样新建一篇笔记、原录音拷到笔记旁边，点句子回听、区分说话人、整理纪要都能用
- **一场转写 = 一篇笔记**：点开始就新建一篇会议记录并打开，停下来全文和录音自动写进去；转写时 `⌘⇧L` 在正文打一个可点的时间戳，点一下录音跳到那一刻；关掉这一场的笔记就等于结束转写
- 和 26.3 的实时转写、整理纪要、问你的笔记（`⌘J`）一起：听、认、记、问，全在本机完成，声音和笔记都不出门

**搬来就能用**（Obsidian 用户最常装的插件功能，直接内置）：

- **链接织完了**：`[[笔记#小节]]`、`[[#本篇小节]]`、`[[笔记#^块]]` 都能跳到位，`[[笔记#` 列出小节供选；`![[嵌入]]` 就地渲染笔记、小节、块、图片、音频、视频；属性里的 `aliases` 参与解析、补全与快速打开；鼠标停在链接上**悬浮预览**；反链面板列出**未链接提及**，点一下就地改成链接
- **命令面板**（`⌘⇧P`）：所有菜单动作都能搜，中文 / 拼音首字母 / 英文都行，含「插入：表格 / 公式 / 提示块…」；`⌘T` 快速打开也认拼音首字母
- **日记月历**：笔记库页底部的月历，有日记的日子有标记，点没日记的日子按模板新建
- **全库待办**：侧边栏「待办」页汇总所有笔记里的任务，认 `📅 日期` 与 `[due:: 日期]`，按 已过期 / 今天 / 明天 / 7 天 / 以后 分段；打勾直接写回原笔记那一行
- **标签改名 / 合并**：标签面板右键就地改名，正文 `#标签` 和属性 `tags:` 一起改，没改到的行一个字节都不动
- **快速捕获**：全局快捷键 `⌃⌥N` 随时弹一个小窗口，敲完回车追加到今天的日记，焦点回到原来的软件
- **属性面板**：属性卡片直接编辑（文本 / 数字 / 日期 / 勾选 / 列表芯片，增删改字段），只动那个字段的几行
- **导出 Word**（.docx）与**导出长图**（PNG，超长自动分张、切在段落边界、带出处角标）；导出成功的提示带「打开」「在访达中显示」
- 还有：文件树排序、同步盘一键（可反悔）、源码模式 `⌘D` 与可选 Vim 键位、`⌥↑` / `⌥↓` 整块移动、脚注点击跳转、`.iml/snippets.css` 自定义样式、`iml://` 链接唤起；修复了切换标签页后 `⌘Z` 会把上一篇内容撤销进当前篇的问题

### 🎙 听得见，问得到（26.3）

- **实时转写**：侧边栏「转写」页点一下开始，边说边出字，停顿后定稿、自动加标点；中文、英语、粤语、日语、韩语都认得。识别在本机完成（sherpa-onnx + SenseVoice，首次使用下载约 240 MB，之后离线可用），声音不上传。转写时可以切到别的面板，状态栏的红点和计时一直在
- **你记要点，全文它来记**：转写全文以一个折叠的 `<details>` 块放进笔记（富文本往返逐字不变，Obsidian / GitHub 里同样是折叠的），你自己记的要点留在上面
- **回听**：转写的同时留一份录音（WebM / Opus，一小时约 11 MB，可以关掉），跟笔记一起存在 `assets/`。在转写面板或笔记里**点任意一句话，录音就跳到那句话开始的地方**；停了可以接着录，时间戳和录音首尾相接
- **整理纪要**：结合你记的要点，让对话模型（本机小模型就行）列出「议题与结论」和「待办」，插在转写全文前面；长会议自动分段提炼再合并
- **丢不了**：没放进笔记就退出了，下次打开转写和录音都还在；正在转写时退出会先问一句
- **问你的笔记**（`⌘J`）：用大白话问，不用想关键词。先在向量索引里找出最相关的几段原文（向量召回 + 字面重排），再让模型只根据这几段回答，**每个结论标着出处，点一下跳到原文那一段**；笔记里没写的，它会直说没有。转写的内容同样问得到
- **智能 → 实时转写…**：能不能用一眼看清；语音模型的下载与删除；录音留不留；选麦克风、点「试一下」看音量条 —— 没有声音进来时转写面板也会提醒
- **更轻更快**：安装包 Windows 250 MB → 79 MB、macOS 153 MB → 88 MB；启动要加载的代码少了三分之一；发现新版本只主动提醒一次，写明更新了什么，并直接给出这台电脑该下的安装包

### 🧳 放心搬进来（26.2）

- **原样保存**：富文本模式保存时，没碰过的块直接写回文件里的原文——表格的对齐填充、列表用 `*` 还是 `-`、标题后空不空行、Setext 标题、CRLF、文件末尾的换行都保持原样；只有你编辑过的那一块才会重新生成
- **不再改花**：`my_var` 不会变成 `my\_var`，`[1]` 不会变成 `\[1\]`，`C:\Users` 不会变成 `C:\\Users`；删除线、`<u>` `<kbd>` `<sub>` `<sup>` `<mark>`、`==高亮==`、`<details>`、HTML 注释、脚注、带链接的徽章图、链接标题、表格对齐、嵌套任务列表都能完整往返
- **属性（frontmatter）**：文档开头的 YAML 显示成可折叠的属性卡片，双击改原文；注释、缩进、引号、字段顺序一律不动
- **提示块**：`> [!NOTE] 标题`（GitHub / Obsidian 通用，含折叠标记与 Obsidian 的扩展类型）渲染成彩色卡片，类型可在卡片上切换；在引用块里敲 `[!NOTE] ` 即可转换
- **标签**：正文里的 `#标签`、`#项目/子项` 与属性里的 `tags:` 汇总到侧边栏「标签」页，点击正文里的标签直接筛选
- **`[TOC]`** 自动目录、**行内公式** `$E=mc^2$`（KaTeX 渲染，单击修改）、**脚注**与 HTML 块按原文保留并就地预览
- **版本历史**（`⌘⇧H`）：每次保存在本机留一个版本，逐行对比、一键恢复；别的编辑器或同步盘写进来的内容在被覆盖前也会先留底。历史放在应用数据目录，不污染笔记库
- **粘贴与图片**：粘贴 / 拖入的图片自动压缩成 WebP（实测 3.7 MB → 220 KB）并存到笔记旁的 `assets/`；相对路径的图片能在编辑器里正常显示；粘贴网址自动取网页标题；源码模式粘贴网页内容自动转 Markdown；「视图 → 清理未引用的图片」移入废纸篓
- **相关笔记与语义搜索**：26 MB 的本机嵌入模型（BGE-small-zh，可选 BGE-base / Qwen3-Embedding）给笔记库建向量索引，目录面板推荐相关笔记，搜索时用词不同也能找到；与本机模型共用 llama-server 运行时，全程不出这台电脑
- **AI 与隐私**：状态栏始终显示 AI 请求发往本机还是云端；设置里可一键关闭全部 AI，关闭后主进程也不再向任何模型服务发请求
- **快速打开**（`⌘T`）：敲几个字跳到笔记——Obsidian 用户的肌肉记忆。匹配标题、文件名和文件夹，多个词用空格隔开（「周会 项目」），没输入时列最近打开的，一篇都没匹配上时回车直接新建
- **标签页**：`⌘W` 关闭、`⌘⇧T` 重开刚关的、`⌃Tab` 切换、`⌘1`~`⌘9` 直达；右键批量关闭（其他 / 右侧 / 已保存的 / 全部）；有未保存修改的标签页显示圆点
- 专注模式（`⌘⇧.`）、正文字体 / 字号 / 行距 / 页宽、源码模式左右滚动同步、拼写检查开关、导出单文件 HTML

## 本地运行

```bash
npm install
npm run dev          # 开发模式（渲染进程的报错会转发到终端）

npm run build:mac    # macOS 安装包（同时生成 arm64 和 x64）
```

测试覆盖 Markdown 往返保真（40 多种写法逐字比对）、原文保留、转义、增量序列化、查找匹配、会话恢复、全文与标签索引、版本历史、图片整理、语义分块与向量库、本机模型托管、快速打开的匹配排序、标签页的关闭队列与重开栈、AI 就绪判断、问答的检索重排与引用、转写的分句节奏 / 转写块往返 / 草稿找回 / WebM 时长补写、安装包体积守卫、更新提醒的安装包选择，目前 376 个用例。其中一组专门逐例比对主进程与渲染进程各自的「AI 请求发往哪里」判断——状态栏按一份显示、请求按另一份路由，两份必须给出同样的答案。

**26.3.0（2026-09-20）— 听得见，问得到**

- **实时转写**：本机识别（sherpa-onnx + SenseVoice int8 + silero VAD，模拟流式：每 0.5 秒重解码当前这一句，VAD 结束时定稿），识别跑在独立的 utilityProcess 里，原生模块与模型首次使用时下载到应用数据目录；麦克风采集关掉了 Chromium 的降噪 / 自动增益（它们会吃掉每句话的第一个音节）；可选麦克风、试音、数字静音提醒

- **草稿**：没放进笔记的转写（文字存 localStorage、录音落盘到应用数据目录）退出后可找回
- **问你的笔记**（`⌘J`）：分块级向量召回 → 检索时重读原文并重新分块 → 字面重合度重排（CJK 二元组 + 拉丁 / 数字词）→ 只根据这几段回答并标注出处；追问时带上一问；模型拒答时不摆来源；点出处打开笔记并定位
- **侧边栏功能写进当前笔记**：新增 `editTabContent` —— 先刷回编辑器里还没写回的字，富文本编辑器即使有焦点也重载、光标留在原地（此前有焦点时外部写入会被忽略，再敲字还会把它覆盖掉）
- **安装包瘦身**：`dependencies` 清空（界面库早已由 Vite 打进 `dist/`，此前整棵 `node_modules` 又被塞进 `app.asar` 一遍，191 MB → 12 MB）；Windows 每种架构单独出包；Chromium 语言包只留中英文；macOS 不再打没人用的 zip
- **启动**：Mermaid 用到才加载；代码高亮从近 200 种语言收到 65 种常用的，主包 3.36 MB → 2.23 MB
- **更新提醒**：同一版本只主动提醒一次、应用常开时每天检查、摘出发布说明的要点、按平台与架构直接给出安装包
- **界面**：侧边栏功能页的空状态重做（图标、要点、可点的例子）；「智能」菜单里转写只占一项；淡色底跟随主题色
