这一版没有新功能，只把界面上的说明文字重写了一遍：小字只回答「不做会怎样」，设计理由和实现细节都拿掉了。**如果你还停在 26.4，这次更新会一并带上 26.5 的全部新功能**，下面一起列出来。

### 把界面上的话说清楚（26.5.1）

- 设置最底下那块写错了：「安全逃生舱 / 销毁本地记忆快照 / 一键抹除全部现场」，还提到了这个应用里根本不存在的「星标状态与记忆目录」。
  它实际做的事很朴素——关掉所有标签页、清空最近打开和星标，笔记和设置一个字节都不动。现在就这么写：**重置界面状态**
- 同一页里的「知识库」「起始控制台」「静默自动保存」「恢复上次会话」，改成**笔记库 / 首页 / 自动保存 / 上次打开的笔记**
- 三个最常打开的弹窗瘦身：本机资源的副标题原本用 60 个字讲内存调度策略，现在一句话；
  实时转写里那条 71 个字、套着括号和分号的录音说明，缩成「录音存在笔记旁的 assets 里，一小时约 11 MB」；
  「生图时总是先腾地方」这个开关不再一边勾着、一边写「默认不开」
- 出错时说人话：以前配图失败会把服务端返回的原始内容前 200 个字糊在状态栏上，
  现在只说「火山引擎没有返回图片，换个模型或稍后再试」，技术细节留在日志里
- 标点与叫法统一：省略号一律用「…」；本机 / 本地、笔记 / 文档、点一下 / 点击不再混着用

说明文字整体短了四成，但没有一个功能因此变得难懂——拿掉的都是原本就不该占地方的话。
为了防止它们「改完又长回来」，新增了一组自动检查跟着测试一起跑。

### 本机生图：说一句想要什么，这台电脑自己画（26.5）

- 空行按空格唤出 AI 气泡 → 选「AI 配图」 → 说一句想要什么。全程离线，画完的图存在笔记旁边
- 两个模型可选（用到才下载）：**Z-Image Turbo**（约 6.7 GB，八步出图，M 系列上 768 × 768 一张约三分钟）或 **Qwen-Image 2.1**（约 10.3 GB，更细但慢七倍）
- 出图要几分钟，所以正文里先占一块位：上面写着提示词和进度，画完原地换成真图；气泡关了也没关系，点占位块就能取消

### 几个模型，一台电脑，自己排队（26.5）

- 对话与嵌入合成一组一起启停，转写用时自动起、用完自己退，生图出图时才起
- 占多少内存按实测算，不够时才请人让位、让完的自己回来；对方正在回答就等它答完，而不是直接报「内存不够」
- 「智能 → 本机资源」一眼看清谁在跑、各占多少、空闲多久自动停

### 标题与列表折叠（26.5）

- 标题左边的箭头收起整节，列表项有子项时也能收；`⌥⌘[` 折叠、`⌥⌘]` 展开
- 收起来的只是不显示，文件一个字都没动；光标移进去会自动展开

### 转写能收电脑放出来的声音（26.5，macOS）

- 网课、戴着耳机开线上会议时，对方说的话以前收不到；现在「转写 → 收音设备」里可以选**系统声音**
- 第一次用系统会请求「屏幕录制」权限；识别照样在本机完成，声音不上传

### 复制为公众号格式，日记月历按字数填色（26.5）

- `⌘⇧P` 搜「公众号」，选个主题、看着手机预览调，一键复制，粘到公众号编辑器里就是排好的版
- 侧边栏的月历按这一天写了多少字填深浅；新建日记跟着你已有的目录习惯走，`日记/2026/09/2026-09-23.md` 这种分法也认
