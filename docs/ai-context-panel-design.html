已经定下来的（三版共用）

  • 入口：侧栏图标栏里新加一个页签，紧挨「笔记库」下面；「智能 → AI 上下文…」那个弹窗撤掉，命令行安装搬进面板
  • 记忆库：笔记库/记忆/，一领域一篇，纯 Markdown 列表，一条一行带来源；工具只追加，不删改
  • 来源：只读工具表（electron/aiContext/tools.ts）里列的路径；不碰 SQLite、凭证、会话记录
  • 索引：这些文件单独建一份索引，和笔记库的分开。好处是记忆之间的 457 处 [[链接]] 能点、反链能看；笔记库的搜索、待办、文件树不受影响
  • 编辑：点一下在编辑区打开，就地改，改的就是 ~/.claude/CLAUDE.md 本身；工具同时在写时，外部改动保护接住
  • 不做：不进待办、不进语义索引和「问笔记」、不在工具目录里新建文件（新建一律落 记忆/）、点到没有的链接不弹「新建笔记」
  • 空状态：本机一个工具都没有、也没有 记忆/ 时，用 PanelIntro：这是什么、怎么会有内容、一个「建立记忆库」按钮

分期（按 C 做）

期做什么要动的地方
一期页签与面板（记忆库 + 来源树 + 搜索）、独立索引、就地打开编辑、[[链接]] 与反链、提炼弹窗（不用模型）、iml memory、导出弹窗、撤掉旧弹窗SearchIndex 支持多根并在根上不跳点目录；新 AiContextPanel.tsx；链接解析按文件归属选索引；aiContext/harvest.ts；CLI 加子命令
二期同步弹窗（标记块、备份、清单确认）；来源行的「已同步 / 未同步」状态aiContext/sync.ts，先例是 iml-switchboard 写 AGENTS.md
三期模型提炼：合并说同一件事的几条、把单个案例泛化成规矩。做成技能在 Claude Code 或 Codex 里跑，读 iml memory harvest --json，编辑器不碰模型一个技能目录，加每周复盘的 hook

要你定的

  1. 面板选哪版：A、B 还是 C。我推荐 C
  2. 页签标签：「上下文」「记忆」还是「AI」。我推荐「上下文」
  3. CLAUDE.md 怎么办：二期同步时，Claude Code 这份是内联「我是谁」（和别家一样），还是改成 @~/Personal/笔记库/记忆/我是谁.md 引入（只有它支持，不会漂）。我推荐引入；这一步动的是你的 ~/.claude
  4. 来源文件能不能改：就地可编辑（推荐，一个编辑器管所有 Agent 的规则），还是只读加「在访达中显示」
