## 26.6.0 — 打字停一下，它接着写

写着写着停下来想下一句，光标后面会浮出一小段灰字。合意就按 `Tab` 收下，不合意接着打字，它自己消失。

模型和写作助手是同一个，本机模型就够用——笔记不出这台电脑，断网也能写。默认是关着的，想用在「智能 → 自动续写…」里开。

### 自动续写

- **怎么用**：「智能 → 自动续写…」打开开关，回到正文打字，停顿一下灰字就出来；`Tab` 收下，`Esc` 或者接着打字就消失
- **停顿多久可调**：0.5 秒 / 1 秒 / 2 秒。打字快的人调长一点，想边写边看建议的调短
- **接着打也不打断**：你打的字正好和灰字开头一样时，灰字跟着缩短，而不是整段没掉
- **只在该出现的地方出现**：光标停在普通段落末尾、这一段里已经有字才去要；代码块和标题里不打扰，选中文字、输入法正在拼字、正在打 `/` 或 `[[` 时也不打扰
- **不抢别人的内存**：本机模型正给生图或转写让位时，这一次直接跳过。出错不吭声——写到一半弹一条报错比不续写更烦人
- **灰字只是画上去的**：文档一个字都没动，这时候保存，落盘的还是原文
- `⌘⇧P` 搜「自动续写」可以随时开关，不用进设置

### 把话说得更准

- 启动页：Windows 上的快捷键不再写成 `Cmd`；按钮改叫「新建笔记 / 打开文件 / 设置」
- 「星标」统一叫「收藏」，和右键菜单、侧边栏对上了
- 空状态说清下一步：目录空着时说「这篇笔记还没有标题」，收藏空着时说「在笔记库里点一下笔记旁的星星就能收藏」
