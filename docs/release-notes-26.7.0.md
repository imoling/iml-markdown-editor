## 26.7.0 — 东西放哪，你说了算

这一版改的都是「放在哪」的事：笔记从哪儿打开、图片放在笔记里还是旁边、换到哪个笔记库、十几 GB 的模型放在哪块盘上。

### 下载

| 平台 | 安装包 |
|---|---|
| macOS Apple Silicon（M 系列） | `iML.Markdown.Editor-26.7.0-arm64.dmg` |
| macOS Intel | `iML.Markdown.Editor-26.7.0-x64.dmg` |
| Windows（绝大多数电脑选这个） | `iML.Markdown.Editor-Setup-26.7.0-x64.exe` |
| Windows on ARM（骁龙本等） | `iML.Markdown.Editor-Setup-26.7.0-arm64.exe` |

安装包仍在 80 ~ 90 MB，模型用到才下载。未做 Apple 公证，首次打开若提示「无法验证开发者」，在访达里右键应用选「打开」即可。

### 拖进来就打开

- **笔记**：`.md` / `.txt` 拖到窗口任何位置——侧边栏、正文、状态栏、起始页——松手就开成标签页，一次拖几个也行
- **文件夹**：在当前笔记库里的，文件树展开到它；库外的先问一句再换库，因为换库之后日记、快速捕获和搜索都会跟着换过去
- **图片**：拖到正文下面或两边的空白处，接到正文末尾。笔记短的时候正文只占页面上面一小块，以前松手在空白处是插不进去的
- 别的文件（比如 PDF）会说一声打不开，不再把内容塞进正文

### 图片写进笔记里

- **怎么开**：设置 → 粘贴与输入 → 图片存放位置，选「笔记里」。之后粘贴、拖入、对话框上传、AI 配图的图片压缩后直接写进正文，整篇只有一个文件
- **代价**：文件大三分之一左右；这种方式一律压缩，不看「粘贴图片时压缩」的开关
- **没保存过的新笔记也能插图**，不用先存盘
- **源码模式**把那一长串折成一个小标签（「… 164 KB …」），只是显示上折起来，文件内容不动；查找不会搜到它里面去
- 带图的笔记照样进全库搜索、反向链接和日记月历，照样有版本历史——历史里同一张图只存一份
- 状态栏的字数、给模型的上下文都不把图片算进去

### 切换笔记库

- **最近的笔记库**：侧边栏库名后面多了一个小按钮，点一下列出最近用过的（最多 8 个），再点就换过去。macOS 菜单栏「文件 → 最近的笔记库」里也有一份
- 「文件」菜单里加了「切换笔记库…」（`⇧⌘O`），以前只在起始页和命令面板里有
- 文件夹已经不在了的，点它会说一声并从名单里去掉

### 模型存放位置

对话、嵌入、转写、生图的模型和运行组件加起来十几 GB，原来只能放在应用数据目录里。现在可以换（[#6](https://github.com/imoling/iml-markdown-editor/issues/6)）。

- **怎么换**：智能 → 本机资源… → 模型存放位置 → 更改…
- **已下载的会搬过去**：同一块盘上一瞬间，跨盘会显示进度。期间本机模型先停止，搬完对话模型自己回来
- **出了错会撤回**：磁盘满了、盘被拔了、没权限——原来的位置照样能用
- 有模型正在下载或正在用时不搬，等它完成再换
- 指到一个已经放着模型的目录，那里的模型直接认回来，不用重新下载
- 放在移动硬盘上、盘没接上时应用照常能开，面板上会说清楚，并给出「恢复默认」
