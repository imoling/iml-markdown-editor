## 26.9.0 — 和 Agent 一起改笔记，谁的字都不丢

越来越多的人让 Claude Code 这类 Agent 直接改笔记，这一版把这件事做稳：外面改了，页面马上跟上，两边都改过时由你决定。另外补上了两个大家一直在问的基本功能：文件能移动，图片能复制。

### 下载

| 平台 | 安装包 |
|---|---|
| macOS Apple Silicon（M 系列） | `iML.Markdown.Editor-26.9.0-arm64.dmg` |
| macOS Intel | `iML.Markdown.Editor-26.9.0-x64.dmg` |
| Windows（绝大多数电脑选这个） | `iML.Markdown.Editor-Setup-26.9.0-x64.exe` |
| Windows on ARM（骁龙本等） | `iML.Markdown.Editor-Setup-26.9.0-arm64.exe` |

未做 Apple 公证，首次打开若提示「无法验证开发者」，在访达里右键应用选「打开」即可。

### 外面改了，这边跟得上（[#9](https://github.com/imoling/iml-markdown-editor/issues/9)）

- 没有未保存的改动：页面直接更新，不用重新打开，光标停在编辑器里也一样；不在笔记库里的文件也跟随
- 这边也改过：编辑区顶部出现提示，可以选「载入新版本」「另存为」或「保留我的」。选之前自动保存不写盘，外部的改动不会被盖掉；选「保留我的」时，外部版本留在版本历史里
- 文件被移走或删除：不再自动写回原处，由你决定存到哪
- 应用关着的时候文件被改过，重启恢复未保存内容时同样按两边都改过处理

### 文件和文件夹能移动

拖到文件夹上，或右键「移动到…」。笔记里指向图片、附件的相对路径会跟着改，图片不会裂；整个文件夹一起搬时，指向文件夹里面的路径不动，指向外面的跟着改。目标位置有同名文件时不覆盖。

### 图片能选中，也复制得走

- 点一下图片有选中框，`⌘C` 复制的是真图片，WebP 也会转成 PNG，贴到微信、Word 都有图
- 文字连图片一起选中复制，图片也带得走；贴回笔记时仍用原来的路径，不把整张图写进文件

### 查找、大纲、编号、链接

- 在查找框里点上下箭头或按回车，页面会滚到匹配项，放在视野中间
- Windows 换行（CRLF）的文件，大纲不再是空的
- 富文本里列表中间插一段文字，后面的编号接着数。源码模式仍按文件里写的数字显示
- `asset.py`、`README.md` 这类文件名不再变成链接，打字、粘贴文字、粘贴网页内容都一样。代价是打字输入 `github.com` 这种不带协议的域名也不再自动变链接

### 其它

- 模板目录里的文件不再出现在快速打开、`[[` 补全、标签数和语义索引里；改标签时模板仍会一起改
- 许可证由 CC BY-NC 4.0 改为 MIT
