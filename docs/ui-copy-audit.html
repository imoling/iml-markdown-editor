  • 省略号：正在检查更新...（App.tsx:564）、AI 正在生成内容...（StatusBar:116）、加载中...（两个配置弹窗）用的是三个点；另外 104 处用的是「…」。

三、文案规范（建议写进 CLAUDE.md，以后照着写）

信息层级：一个控件最多三行，第三行通常不该存在

行写什么例
标题这个控件是什么，用动词或名词短语，≤ 8 字粘贴图片时压缩
副文案（可选）只写不做会怎样、代价、例外，≤ 25 字，且必须是标题推不出来的信息大图转成 WebP，通常小一半；动图不动
第三行不要有。要解释原理 → 新特性介绍 / README；要免责 → 全局说一次—

该写的

  • 不可逆、会花钱、会花很长时间的后果：删除后需要重新下载 6.7 GB
  • 非直觉的副作用：停掉后下次用时自动加载，约十几秒
  • 生效范围与时机：只在源码模式生效、改动从下一场转写生效
  • 用户看不见的位置：存在笔记旁的 assets 里

不该写的

  • 标题的同义复述（正文字体 / 富文本与预览的正文）
  • 设计理由与权衡（默认不开：内存真不够时本来就会请它们让位，不必每次都折腾）
  • 实现细节（钥匙串、DPAPI、llama-server、SHA256、GGUF、Base URL）
  • 重复的隐私承诺 —— 全应用只在两处说：状态栏的 AI 指示器、各能力弹窗的顶部副标题，各说一次
  • 操作说明书式的引导（点「试一下」看看麦克风有没有在收音 —— 按钮就在旁边）

术语表（一个概念一个词）

用不用备注
笔记库知识库、资料库、工作区SettingsModal:276 是唯一漏网的
笔记文档「文档」只在指非 Markdown 文件时用（导出 Word 文档）
本机本地「本地」只用于「本地文件 / 本地上传」这种物理含义
启动 / 停止起来 / 停掉 / 起停按钮和状态用书面词，正文可以口语
点一下点击全应用口吻偏口语，统一到「点一下」
设置里设置中—
让位腾地方、腾干净已经是这一版的正式说法，界面上只用这一个

标点

  • 中文语境一律全角：：，。「」（）；省略号只用 …。
  • 说明文案不加句末句号（现状 401:71，少数服从多数）；两句以上时中间用「；」，仍然不加句号。
  • 按钮、标签、菜单项不带任何句末标点；进行中的按钮用 正在…（正在保存…）。
  • 数字与单位、中英文之间留一个空格：8.9 GB、90 分钟、Markdown 文件。
  • 状态词：进行中 正在 X…，完成 已 X，失败 X 失败：原因。

错误信息三段式

<发生了什么>：<一句人话的原因>
[详情]  ← 折叠，放原始响应 / HTTP 码 / 堆栈

例：AI 配图失败：火山引擎没有返回图片
    详情 › HTTP 400 InvalidParameter: model not found

扫描器踩的坑

第一版护栏漏了 跨行的 JSX 正文——最长的那几条（转写设置里 67 字讲声纹的那段、清理图片弹窗里 69 字的说明） 正是写成多行 JSX 才躲过按行匹配的。现在整篇一起匹配，并先剥掉注释。

更重要的不是字数：界面不再替用户做阅读理解，用户才会相信这些功能是稳的。 现在每个开关下面都挂着一段解释，传递出来的潜台词是「这功能有点复杂，我得先跟你解释一下」—— 而成熟应用的潜台词是「按就行了，出问题我会告诉你」。
